## Sistema de Gestión de Empleados

# Uso de IA

- Uso de IA Generativa para ayuda de comprensión de errores de código,
la IA no genero una sola linea de código.

# Tecnologías Utilizadas

- Java
 -- Spring Boot
- React
 -- Axios
 -- Bootstrap
- MySQL

# Caracteristicas

- CRUD de empleados
- Listado de empleados
- Edición de empleados
- Eliminación de empleados

# Ejecución

## Backend
```bash
cd backend
./mvnw spring-boot:run
```

## Frontend
```bash
cd frontend
npm install
npm start
```
